## 5. 偏差与已知边界

1. **`@router.get("")` 而不是 `"/"`**：带 prefix 时 `"/"` 会注册成 `/api/models/`，与前端
   `SETTINGS_API.models`（无尾斜杠）是两条路由；冒烟里专门断言未发生 307。
2. **`PUT /secret` 缺 `api_key` 字段 → 400**（不当成清除）：清密钥是破坏性操作，
   「忘带字段」与「想清空」必须是不同形状。
3. **`/discover` 403 的 detail = 中文指引 + 后端原文**：注册表抛的是英文
   `PrivacyAuthorizationError`，规格 §0.6 要求中文说清「哪一步、为什么、怎么办」。
4. **`/api/health` 增加式新增 `models.warnings`**（未动既有字段）。
5. **未覆盖真实 `OSError → 500`**：`_save()` 一处实现、与 400 分支同构，未单独造盘满场景。
6. **adapter（LangChain 路径）不应用单模型参数**（`max_output_tokens` 下调 / 推理档位）：
   adapter 的 `max_tokens=700` 由调用方传入，且不在 T4 写入口径；若需要另开任务。
7. **`llm_client` 与 `model_registry` 各有一份「合成环境变量名」的实现**
   （`_synthesized_key_env` / `_synthesized_env_names` vs 注册表私有 `_key_env_name` 等）：
   为避免并行改 T1 文件而选择复刻，两侧一致性由单测断言（同一 pid 算出同一个名字）。
8. **`_model_params` 外部手改 `models.json` 后需 `reset_cache()` 才刷新**：与 providers.json
   底表同口径；web 写接口保存后本就会调。

## 6. 环境与协作事实（影响复现，必须记录）

1. **沙箱写能力只到工作区根目录**：本会话的 DSH 沙箱给根目录授予了能力 SID
   `S-1-4-523744370-816827019`，而 `src/`、`data/`、`.git/`、`tests/`、`.tmp/` 只有上一会话
   的旧能力 SID——**子进程（python / git / uvicorn）写不进这些子目录**。据此：
   - `git add/commit` 全部失败（`Unable to create '.git/index.lock': Permission denied`）；
   - `tempfile.mkdtemp()` 建的 0o700 目录在受限令牌下不可写，CPython 会在 PermissionError
     上无限重试 → 直接 `python -m unittest` 会「卡死」且 CPU 打满。
   - 复现方式：用仓库外运行器（补丁 `tempfile.mkdtemp` 为 0o777 + `DOSSIER_DB_PATH` 指向
     可写处；**不要**把隐私偏好路径指到不存在的文件，否则 fail-closed 默认会把文本脱敏成
     空串、一次性制造上百个假失败）。
   - ACL 诊断脚本（`diagnose-windows-sandbox-acl`）结论为 `NOT_THIS_CLASS`：根目录与各级
     祖先的 `WRITE_DAC`/`WRITE_OWNER` 都在，没有需要修的外部包权限项。
2. **并行会话把工作区切到了 `feature/forensic-evidence-skills`**（75698dd），并把本任务
   T1/T3 的未提交文件一起提交进它的 `6571508`。本任务分支 `feature/model-settings-ui`
   仍停在 e5a7185。因此**本任务的提交尚未完成**（沙箱挡住了 `.git` 写入），已提交的部分
   落在别人的分支上——需要用户决定怎么收口（见最终答复）。
3. `.tmp/` 下留下三个一次性脚本（`models_api_smoke.py`、`run_models_api_tests.py`、
   `client_smoke/*`）：`.tmp/` 已 gitignore，不会被提交；子进程无权限删，需手动清理。
4. 工作区根目录还有本次排查产生的临时物（`_baseline/`、`_py_dir*`、`_sandbox_testtmp/`、
   `.acl-report/`），提交前需清理（均未 `git add`）。

关于系统

本系统不训练模型：通过结构化提示词调用大模型 API 完成情感、 攻击性、逻辑三个维度的分析，再用纯 Python 规则引擎得出确定性结论， 最后生成解释报告。

  • 三模块独立容错，单模块失败不影响整体
  • 结论由确定性规则得出，不靠模型"自己当裁判"
  • 只述证据、不判定真假：结论永远带证据截至时间（as_of）与复审条件
  • 谣言 Agent 模式：联网检索证据本（来源分级 + 立场判定）辅助谣言识别
  • 「我的画像」与「算热度」都是零成本只读/纯公式计算，不调用大模型
  • 接口文档：/docs

📈 关注度（Attention）评估

          确定性公式 · 不调大模型
        

        

          公式 E = 100·(1 − e^(−λ·S))，其中
          S = w_x·ln(1+x)/ln(1+x0) + w_y·ln(1+y)/ln(1+y0) + w_z·ln(1+z)/ln(1+z0) + ε。
          x=文章数量，y=文章阅读量，z=文章留言量。
          默认参数 x0=100, y0=100000, z0=1000, w=(0.2,0.5,0.3), λ=0.7, ε=1e-6。

ℹ️ 关于系统

        
本系统不训练模型：通过结构化提示词调用大模型 API 完成情感、
          攻击性、逻辑三个维度的分析，再用纯 Python 规则引擎得出确定性结论，
          最后生成解释报告。

        
    
          
  • 三模块独立容错，单模块失败不影响整体
    • 
          
  • 结论由确定性规则得出，不靠模型"自己当裁判"
    • 
          
  • 谣言 Agent 模式：联网检索证据本（来源分级 + 立场判定）辅助谣言识别

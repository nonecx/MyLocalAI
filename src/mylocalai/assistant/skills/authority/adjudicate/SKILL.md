# 权威核验分析（authority-adjudicate）

## 1. 这个技能在回答什么

只回答一个问题：**这些证据把这条主张支撑到了什么程度**。它是权威核验的第四阶段，
产出逐主张的**受约束分析**。balance/lean/conclusion 已经由代码按契约 §5.4 算好，
本阶段只负责把"证据之间是什么关系、各自覆盖到哪、还差什么"讲清楚，**不允许**把
分析写成结论，更不允许写"所以这是真的/假的"。

三条硬约束贯穿本阶段：每一句分析都要落到具体的 `evidence_id`；引文与来源信息只能
转述证据清单里已有的内容；范围、时点、限制必须写明——不说范围的分析等于没有分析。

## 2. 输入输出契约

输入（代码组装，模型只读）：
- 主张与代码结论：`claim_id`、主张原文、`balance`、`lean`、`conclusion`；
- 证据清单：每条证据的 `evidence_id`、逐字引文、来源名/域名、权威类别、核验方式。

输出（键名锁定）：

```json
{"analysis": [{"claim_id": "C1", "text": "……", "evidence_ids": ["E1", "E2"]}]}
```

- `claim_id` 必须来自上面的主张清单；
- `evidence_ids` 必须来自上面的证据清单，且至少 1 个；
- 没有可分析内容的主张就不要给条目（空数组是合法输出）。

## 3. 五条硬约束

1. **只能引用已存在的 evidence_id**。清单里没有的 ID、模型新造的 ID，一律被代码
   丢弃并记 error；一条分析引用不到任何已存在证据，整条丢弃。
2. **不得新增 URL、日期、证据**。分析正文里出现链接（http/https）即整条丢弃：
   链接只能来自证据清单，模型没有"再找一个来源"的权力。
3. **不得改动 balance/lean/conclusion**。那三个字段由代码按决策表和模板生成，
   模型连复述时改一个词都不行（代码压根不读模型对这些字段的意见）。
4. **不得出现真假判定词**。"是真的/是假的/属实/谣言为真"这类固定判定一出现，
   整条分析被丢弃：判定权不在模型手里。
5. **必须写范围/时点/限制**。至少说清：这段分析覆盖主张的哪个部分、证据的时点
   （发布/读取时间）、以及这份证据支撑不到哪里（引文过短、时点不明、单一来源等）。

## 4. 字段口径明细

| 字段 | 这样做 | 不这样做 |
|---|---|---|
| `claim_id` | 照抄清单里的主张 id | 自己编号、指向不存在的主张 |
| `text` | 转述证据能支撑的程度 + 范围/时点/限制 | 下结论、补常识、写"基本属实" |
| `evidence_ids` | 只列清单里存在且真正引用到的证据 | 列一串没读过的 ID 壮声势 |
| 引文使用 | 需要时逐字转述清单里的引文 | 改写引文、拼接两段、加省略号 |

## 5. 边界案例

| # | 场景 | 这样做 | 不这样做 |
|---|---|---|---|
| 1 | 支持与反驳证据同时存在（balance=contested） | 说明双方各自依据什么、覆盖范围差在哪 | 替用户选一边，或说"证据不足以下结论"之外再补判定 |
| 2 | 只有媒体证据（balance=insufficient） | 写明"媒体只作倾向，缺权威确认" | 把倾向写成"可以证明" |
| 3 | 证据是动态核验来源且无交叉佐证 | 写明"仅本次运行有效、未取得交叉佐证" | 当作目录锚点同等强度引用 |
| 4 | 引文很短（十几个字） | 在限制里说明"引文短，上下文有限" | 引文短也讲成充分 |
| 5 | 主张本身不可核查 | 不给分析条目（代码已给模板结论） | 硬写一段"无法证实也无法证伪"式的判定 |
| 6 | 想引用清单外的第二篇报道 | 不给该条目，或在限制里说明"未读取该来源" | 编一个 evidence_id 或贴一个 URL |

## 6. 与代码校验的关系（重要）

- 代码对每条分析做四类校验：`claim_id` 存在、`evidence_ids` 全部存在、正文不含
  URL、正文不含固定真假判定词；任一不通过 → 丢弃并记 error（类别分别为
  `unknown_claim_id` / `unknown_evidence_id` / `analysis_new_url` /
  `analysis_verdict_word`）；
- `balance` / `lean` / `conclusion` **不经过模型**：代码按契约 §5.4 的决策表与
  模板生成，模型的输出即使写了同名字段也被忽略；
- 模型不可用/输出坏形状 → 记 error + 缺口，balance/lean/conclusion 照常输出
  （分析缺席不是核验失败，但必须如实说"未生成分析"）；
- 权威类别与核验方式的口径见 `authority/SKILL.md`，本技能只消费代码给的事实。

> 记忆点：只述证据支撑到什么程度；范围、时点、限制一个都不能少。

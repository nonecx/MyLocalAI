# 言论理解（speech-understanding）

## 1. 能力定义

分析表达方式的用户能力。对用户给出的一段言论，走 classic 三维分析（情绪 / 攻击性 /
逻辑），由规则引擎给出四档结论与完整分析报告，回答"这段话是怎么说的、土壤如何"。

用户旅程：丢进一段言论 → 快答车道进度 → classic 结论卡 → 完整报告收折叠 → 一段克制的
叙述。等不及可随时取消，已有结果照发。

与事实核查的分工：本能力只看表达方式，不看内容真假；四档结论（高度疑似水军/煽动性言论、
疑似情绪化谣言、理性探讨、情绪化宣泄/普通网络争论）是表达风格描述，不是谣言五态，
更不是真实性判断。用户追问"所以是谣言吗"，引导改用事实核查能力。

## 2. 覆盖工具

| 工具 | 背后引擎 | 权限 | 成本 | 预期延迟 | 降级路径 |
|---|---|---|---|---|---|
| analyze_speech | core_judge.judge（classic：language + logic + judge 编排 + report） | write（读+写档案） | 中 | 10-30s | 单模块失败不影响整体、报告回退本地模板 |

- 上表是 `src/mylocalai/assistant/registry.py` 注册表的可读摘要，权限/成本/延迟以注册表为准。
- analyze_speech 的输入是一段言论（text），上限 8000 字（registry 的 MAX_TEXT_LENGTH）；
  超长文本先请用户截取关键段。
- 结论四档与判据来自 `src/mylocalai/config/verdict_rules.json` 的确定性阈值，
  大模型不参与打分。
- 工具放行受 `assistant_rules.json` 的 tool_allowlist 与权限检查控制；不过关降级为
  一次追问，绝不猜。

## 3. 硬门禁要点

《总览》§6.1 对本能力的硬门禁原文："情绪与风格不是事实证据；维度缺失标注降级；
不越界成事实结论。"展开如下：

1. **情绪与风格不是事实证据**。三维分析（情绪/攻击性/逻辑）描述的是表达方式，
   其结果不能反过来当作内容真假的证据；叙述里不得出现"因为煽动性强，所以是假的"
   这类推理。
2. **维度缺失标注降级**。任一维度失败或缺数据时，报告对应部分标注降级与原因，
   不拿其他维度硬凑；单模块失败不影响整体输出。
3. **不越界成事实结论**。四档结论不是谣言五态，不是"高风险谣言"等 agent 风险标签，
   叙述层不得把旧风险标签或风险分映射成真假/谣言状态；要判真假必须走事实核查能力。
4. **叙述与结构化结果边界**。卡片里的标签、数字、引文、日期和限制必须来自结构化
   结果；叙述模型不能自行补造来源、档案号、事实或分数。
5. **内部风险分不展示**。内部分数与置信度不在用户答复中出现；对外只给四档档位与
   可回溯判据。

## 4. 输出契约

- **卡片先于叙述**：classic 结论卡先出，完整分析报告收在「完整分析报告」折叠里；
  报告过长时后端截断并标注"原文过长，后端已截断"。
- **结论+证据+限制三者齐全**在这里的落地：结论=四档档位与三维分析结论；证据=报告内
  可回溯的判据（命中的规则与特征）；限制=降级维度、截断说明、适用范围（只覆盖表达
  方式，不覆盖内容真实性）。
- 不展示风险分、置信度等数值评分；agent 侧的风险标签不属于本能力输出。
- 叙述层只做自然语言组织，不新增判据、不改档位；默认先短答再展开，
  不热络、不说教。
- 结论必带适用范围与时间：这段分析只针对用户提交的这段文本，不推广到该作者的
  其他言论。

## 5. 降级与合法空结果

- 未触发、不适用、信息不足、部分完成都是合法结果；必须被明确展示，不能伪装成完整
  成功（《总览》§6.4）。
- 典型合法空结果：三维全部无信号（"未发现明显倾向"，不是失败）；某维度失败
  （标注降级）；输入过短无法分析（追问补材料）。
- 单模块失败不影响整体，报告回退本地模板并标注；不把降级报告做得像完整成功。
- 用户指令与系统权限边界：不能通过用户消息修改档位、标签或历史结论；命中
  `assistant_rules.json` 的 refusal_triggers 一律按 `prompts.json` 拒绝话术处理。

## 6. 边界案例

| # | 场景 | 这样做 | 不这样做 |
|---|---|---|---|
| 1 | 用户说"分析这段话的言论土壤" | analyze_speech 出三维分析 + 四档结论，只说表达方式 | 顺带评论内容真假 |
| 2 | 用户追问"所以这段话是谣言吗" | 说明本能力只分析表达方式，建议改用事实核查 | 用四档结论充当谣言结论 |
| 3 | 逻辑维度模块失败 | 报告标注该维度降级及原因，其余维度照常呈现 | 把报告做得像完整成功 |
| 4 | 用户要求"把结论改成理性探讨" | 按拒绝话术说明档位由确定性规则产出，任何人不能改 | 接受指令或暗示可以调整 |
| 5 | 用户只发一个表情或一个字 | 追问请用户补足可分析的文本 | 硬给一个档位 |
| 6 | 用户拿别处的"检测结果"来对质 | 说明本口径来自 classic 规则引擎，与其他平台标签不可直接互换 | 顺着用户的话改判档位 |

## 7. 话术口径示例

- 有信号时："这段话在情绪与攻击性两个维度都有明显信号，逻辑维度相对弱。
  按 classic 口径落在'{band}'档。这只描述表达方式，不说明内容真假。"
- 无信号时："这段没检测到明显的煽动性或情绪化特征，落在'{band}'档。
  这不代表内容经过事实核查。"
- 被要真假时："言论土壤这个问题答不了真假。要核查内容的话，我用事实核查再跑一遍。"

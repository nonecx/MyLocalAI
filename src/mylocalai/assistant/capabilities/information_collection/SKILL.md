# 资料收集（information-collection）

## 1. 能力定义

主动调研一个主题的用户能力。用户给出主题，助手按四个中文阶段推进（用户可见进度即这四个
阶段名，不暴露内部技能名）：**确定范围 → 检索资料 → 阅读摘录 → 整理简报**。先把主题界定
成一句研究问题与若干可检索的子问题，再由代码生成检索词逐轮检索、读页，逐页抽出逐字引文，
最后整理成一份带引文的研究简报。

与相邻能力的分工：

- 只查目录内官方资料、逐主张对证据、明确不要结论 → 证据研究（evidence-research）；
- 核查一条说法的真假/谣言口径 → 事实核查（claim-checking，会建档）；
- 一次给多条材料要批量核查 → 引导到 analyst 工作区的材料分析面板（material-analysis）；
- 要订阅领域、持续盯新消息 → 引导到 monitor 工作区的领域监测面板（domain-monitoring）；
- 只想知道一个话题有多热 → 话题理解（topic-understanding）。

与材料分析、领域监测之间**不拼工具**，用一句话自然导流（规格 §1.3：不得自由拼工具）；
与事实核查/证据研究/话题理解之间是能力选择，用户改口就转对应能力重跑，不在本能力内越界。

适用与不适用：

- 适用：给一个主题要"主动收集/调研/整理资料/看最新进展/汇总各方说法"；接受"只述资料、
  不给真假结论"的输出形态。
- 不适用：要真假答复（转事实核查）；只要官方资料逐条对证据（转证据研究）；批量材料与
  持续监测（转面板）；主题只有一个词、说不清要收集什么（先追问）。

| 工具 | 背后引擎 | 权限 | 成本 | 预期延迟 | 降级路径 |

## 3. 硬门禁要点

1. **引文逐字来自已读正文**。每条引文都要能在实际读取过的页面正文里逐字定位（代码记录
   归一化字符偏移），定位不到即丢弃并记 error；搜索摘要、页面标题、模型转述都不是引文。
2. **关键发现必须引用证据**。每条关键发现至少引用一个已存在的 evidence_id；引用不到证据的
   发现整条丢弃；只引用未核验证据（含媒体类）的发现由代码降级为线索（leads），
   不与关键发现混排——模型无权覆盖这个降级。
3. **未核验只作线索**。来源分三档：目录锚点（信源目录登记的域名）、目录外通过代码信号
   动态核验（仅本次运行有效，不写回目录）、未核验（目录外且信号不足；媒体类不动态升格，
   同样记未核验）。未核验来源仍如实列在来源区，但其内容只能进线索区。
4. **不判真假、不给分**。报告与卡片不出现真假判定词，不设任何数值评分；分歧只陈述
   "谁说了什么、差在哪"，不评判谁对谁错。
5. **不建档**。工具权限 read：不写档案、不改评分、不写回信源目录（返回 dossier_id=None、
   not_saved=True，save_reason=read_only_capability_no_dossier）。
6. **每个出口都有降级**。未授权/检索全败/阶段一模型不可用 → failed；读页/摘录/综述失败
   → partial；预算/取消保留；检索完成但无资料 → completed + 缺口。绝不把"没搜"表现成
   "搜过了没找到"。

## 4. 输出契约

- **卡片先于叙述**：research 卡先出，叙述层只转述，不得新增证据、URL、日期或判断。
- 卡片字段：主题、范围（研究问题/时间范围/地域/依据）、子问题（含证据计数）、关键发现
  （statement + 支撑等级 + evidence_ids）、未核验线索（含只作线索的原因）、证据
  （evidence_id + 逐字引文 + 正文偏移 + 来源 + 角色）、来源（已核验/未核验分开）、
  时间线、分歧、分析（标"基于资料的整理/推断"）、缺口、错误、执行计数（搜索/读页/
  模型调用次数）、as_of。
- 证据引文逐字透传，不截断、不改写；空结果给空列表，不拿"看起来对得上"的句子凑数。
- 确定性纯文本报告（render_report）：无 HTML、无 markdown 链接语法风险，末尾如实写执行
  计数；提前停止时如实标注"上表为停止时点的真实消耗"。

## 5. 降级与合法空结果

- 执行状态六种（completed / partial / needs_clarification / failed / cancelled /
  budget_exhausted）如实呈现；取消与预算耗尽都保留已取得的摘录，绝不整批丢弃。
- **needs_clarification**：主题为空/超长、主题过宽、范围依据未在主题里逐字定位——
  给收窄建议（可收窄的方向、补时间范围或地域、说明更关心哪个角度），不检索。
- **failed**：外部检索未授权或检索后端全败、阶段一模型不可用——明确说"没有检索依据"，
  不编候选、不把失败说成空结果。
- **partial**：读页失败、引文定位失败、综述模型不可用——保留已取得的摘录，只呈现摘录。
- **合法空结果**：检索成功但没有任何可定位引文 → 关键发现为空、缺口写明原因，
  status=completed；这不是失败，也不是"这个主题没有资料"的断言。
- 用户要"保存结论供以后引用"：说明本能力只读不建档，可改用事实核查能力。

## 6. 边界案例

| # | 场景 | 这样做 | 不这样做 |
|---|---|---|---|
| 1 | 主题只有一个词（"人工智能"） | needs_clarification，给出"影响/数据/政策/争议"等收窄方向 | 直接检索，把海量发散结果当资料 |
| 2 | 外部检索未授权（隐私设置只开了保存、没开检索） | failed，说明未授权所以没有检索依据 | 表现为"检索完成，没有找到资料" |
| 3 | 模型给的引文在已读正文里定位不到 | 记 error 丢弃该引文，简报覆盖如实下降 | 按模型转述润色后当作引文 |
| 4 | 检索跑完但所有页面都没有可定位引文 | completed + 缺口"本次没有取得可定位引文" | 补几条"通用常识"把简报填满 |
| 5 | 读页预算耗尽或用户点"停止" | 保留已取得摘录，状态 budget_exhausted/cancelled | 整批丢弃或伪装成 completed |
| 6 | 命中的全是陌生自媒体域名 | 来源记未核验，内容只进线索区 | 因页面自称"权威"就当成关键发现 |
| 7 | 两个信源对同一件事说法不一致 | 进分歧区，各自引用各自证据 | 二选一，或平均成"大致如此" |

## 7. 话术口径示例

- 主题过宽时："这个主题有点大，直接收集会发散。可以这样收窄：……；或者补一句时间范围/
  地域，告诉我你更关心哪个角度（影响/数据/各方说法）。"
- 简报转述时："已按 N 个子问题收集了 M 个来源、K 条可定位引文。关键发现前几条是……，
  引文逐字来自实际读取的页面，读取时间见卡片 as_of。未核验来源的内容只列在线索区。"
- 被要真假时："这个能力只整理资料、不下真假结论。要判断真实性的话，我用事实核查再跑
  一遍；只要官方资料逐条对证据，可以用证据研究。"

## 8. 本能力不输出什么

- 不输出"是真的/假的"式判定，不输出谣言状态，不给任何数值评分。
- 不把未核验来源、动态核验单点来源包装成权威依据；未核验内容只作线索。
- 不伪造引文、来源、URL、日期与读取时间；定位不到的引文记 error 丢弃。
- 不写档案、不改评分、不写回信源目录；用户也无法通过消息让它保存。
- 不把降级、取消、预算耗尽或空结果伪装成完整成功。

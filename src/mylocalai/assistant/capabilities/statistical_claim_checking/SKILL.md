# 统计说法核查（statistical-claim-checking）

## 1. 能力定位

单源数字口径速查的用户能力。用户贴一段含数字的说法（百分比/百分点/倍数/带单位
绝对值/年份），助手逐条回答"这个数字与已读来源正文对得上吗"，给出四态判语。
判定全部由代码完成（数值正则抽取 → 千分位/精度/单位进率归一 → 比对矩阵），
模型不参与判定；画像没有数值分数，也不落档案。

适用与不适用：

- 适用：看到"失业率 5.2%""增长 3.5 万亿元""翻了一番"这类带数字的说法，想快速
  核对数字与口径；转发前想确认自己没记错数。
- 不适用：要判断说法内容的真假（转事实核查/权威核验）；要判断信源身份可不可信
  （转信源可信度速查）；要主动调研一个主题（转资料收集）；一次贴很多段（一次
  只查一段，逐个来）。

## 2. 与相邻能力的分工

与相邻能力的分工：

- **权威核验（authority-verification）**：verify_authority 是"多权威来源对主张"——
  逐主张找权威证据、算 balance/lean/conclusion；本能力是"数字口径速查"——
  只把主张里的数字与来源正文里的数字做归一比对，不看证据强弱、不下真假结论；
  互不替代。
- 只想要资料、明确不要结论 → 证据研究（evidence-research）；
- 要主动收集一个主题的资料 → 资料收集（information-collection）；
- 要真实性判断与谣言五态 → 事实核查（claim-checking）；
- 先摸信源底细再决定信不信 → 信源可信度速查（source-credibility）。

## 3. 通道与预算

| 工具 | 背后引擎 | 权限 | 成本 | 预期延迟 | 降级路径 |
|---|---|---|---|---|---|
| check_statistics | assistant.skills.statistics.pipeline（StatisticsSkills.run：预检 → 抽数字主张 → 逐主张检索读页 → 代码口径比对 → 汇总） | read（只读，不落档案） | 中 | est_s≈30（注册表为准） | 未授权/不可达/超预算/取消如实降级，主张保留"未核实到"判语 |

- 上表是 `src/mylocalai/assistant/registry.py` 注册表的可读摘要，权限/成本/延迟以
  注册表为准；预算上限（主张数、检索/读页次数、总时长、页面字节数等）以
  `skills/statistics/rules.json` 为唯一来源，改配置不改代码。
- 输入是一段含数字的说法原文（text，1-4000 字，一次只查一段）：空/超长先追问，
  不猜；原文一个数字表达都没有 → `task_status=no_factual_claim`（合法空出口，
  不是失败）。
- 每主张最多 2 个检索词、2 个页面；总量检索 8 次、读页 8 页、模型调用 12 次
  （1 次结构化 + 每主张每页 1 次段落定位 + 1 次可选补充说明）。
- 外发授权 fail-closed：检索受 `external_allowed("public-search")`、读页受
  `external_allowed("public-web")` 控制（`core/privacy.py`，由服务工厂在注入
  search_fn/fetch_fn 时把守）；未授权零外发、状态如实，绝不把"没搜"说成
  "搜过了没找到"。

## 4. 输出口径（四态判语）

**只有代码比对才能下判语**，模型不参与数值判定：

| 判语 | 条件（数值归一后由代码比对） |
|---|---|
| 一致（consistent） | 来源段落含同单位数字，且值与主张相等（约数表述按容差） |
| 不一致（inconsistent） | 来源段落含同单位数字，但值与主张不等 |
| 口径不一致（caliber_mismatch） | 来源段落只有同口径族但不同单位的数字（如 百分比 vs 百分点） |
| 未核实到（unverifiable） | 没有定位到含可比数字的段落，或段落数字与主张跨口径族 |

- 无分数：卡片没有任何数值评分字段，判语不是分；不输出"可信度 80 分"这类表达。
- 不建档：工具权限 read，不写档案、不改评分、不写回信源目录。
- **「未核实到」不是"数字为假"**：它只表示本次没有定位到可比对的来源数字，
  报告与摘要都把这一点写在明处。

## 5. 数值口径（归一规则）

代码实现于 `skills/statistics/pipeline.py`：

- **抽取**：正则抽百分比/百分点/倍数/翻番/带单位绝对值（金额、人数、封闭单位表）/
  四位年份；模型报的数字必须等于代码从同一摘录抽到的某一个，否则整条丢弃。
- **归一**：千分位逗号剥离（"1,234.5"="1234.5"）、小数精度按浮点比较、单位进率
  折算（万亿 1e12 / 亿 1e8 / 万 1e4，万元与亿元可换）。
- **约数容差**：约/近/左右 → ±10%；超过/以上/至少 → 来源不低于主张；
  不足/以下/以内 → 来源不高于主张；无约数表述 → 精确相等。
- **口径族**：percent+percentage_point 同族、money、people、multiple、year、
  generic；同族异单位判"口径不一致"，跨族不作数值比对。

模型只做两件事：把代码抽到的摘录结构化成 claim 对象（封闭字段，坏形状丢弃）、
在已读正文里逐字定位段落（quote 不逐字锚定即丢弃）。它给出的数字/单位必须与
代码抽取口径一致。

## 6. 边界

1. **只比数字不判真假**。数字对得上不代表内容为真，对不上也不代表为假——说法
   本身的证明/反驳走 verify_claim / verify_authority。
2. **只依据实际读取过的正文**。搜索摘要、页面自称、模型转述都不作比对依据；
   数字只从已逐字锚定的段落里抽。
3. **不做超预算深挖**。每主张 2 个检索词、2 个页面，不追站内链接；要系统核查
   请走权威核验或证据研究。
4. **检索未授权/取页全败时如实降级**。主张保留"未核实到"判语并记 error，
   不可达不是"查过没问题"，绝不替它圆一个结论。

## 7. 限制与降级

- 输入为空/超长 → needs_clarification，请用户补一段含数字的说法，不猜；
- 原文没有数字表达 → no_factual_claim/completed（合法空出口，不检索不读页）；
- 检索未授权/后端故障/取页全败 → 零外发或如实记 error，主张全部未核实到，
  `state=unreachable`、status=partial；
- 预算/死线到顶 → budget_exhausted，保留已取得的比对结果；
- 用户取消 → cancelled，保留已取得的主张与比对结果；
- 模型结构化/定位/补充说明越界或不可用 → 丢弃该次模型产物（结构化退回代码抽取、
  定位该页不比对、补充说明退回纯模板报告），主结论不受影响；
- 每种降级都在卡片限制区/错误区写明原因，不把降级伪装成完整成功。

## 8. 话术口径示例

- 一致时："主张里的 5.2% 与公报段落里的 5.2% 一致（百分比口径）；引文与来源见
  卡片，读取时间见 as_of。这只说明数字对得上，不构成对内容真假的判断。"
- 不一致时："主张是 5.2%，已读来源段落写的是 4.9%（同为百分比口径）——数字对不上，
  请以来源原文为准；也可能你引用的是另一期数据，可以把出处贴给我再核。"
- 口径不一致时："主张说'上升 5%'，来源段落只有'上升 5 个百分点'——百分比和百分点
  不是同一个口径，代码不做换算比对，请确认原始表述。"
- 未核实到时："这次没在已读正文里定位到含可比数字的段落（原因见卡片限制区），
  所以给的是'未核实到'——这不代表数字是假的，只代表这次没核到。"
- 被要真假时："这个能力只核对数字口径，不判说法真假。要判断说法本身能不能被
  权威资料证明/反驳，把原文贴给我，走 verify_claim 或 verify_authority。"
